# Phase 5 Scope Lock

This is the current authoritative scope for Household Bills 0.5.0.

- No local AI, cloud AI, language model runtime, AI sidecar, or AI assistant is included or planned for the release path.
- The deterministic Rust financial engine remains the source of truth for bill funding, recommended payment dates, safe-to-spend calculations, warnings, savings commitments, and debt-plan calculations.
- Phase 5 must be fully tested on Windows before installer/release hardening begins.
- The central user workflow is explicit: show what bill to pay, the recommended date to pay it, its actual due date, and which paycheck(s) or current cash funded it.
